# Dig Funding

Dig Funding is a static web application that helps archaeologists share their projects and connect with supporters who are eager to fund new discoveries. Inspired by platforms like Kickstarter and Patreon, the experience is tailored specifically for archaeology with global projects, exclusive content for backers, and tiered rewards.

## Features

- **Discover 50+ example projects** featuring excavations, conservation, and community-led research spanning every continent.
- **Search and filter** by keyword, project topic, country, and start year to quickly surface areas of interest.
- **Exclusive content highlights** show what supporters receive when they back a project, including livestreams, workshops, and behind-the-scenes media.
- **Tiered rewards lists** outline perks for different contribution levels, helping backers understand the impact of their support.
- **Fully client-side** implementation with semantic HTML, accessible design, and responsive styling suitable for GitHub Pages hosting.

## Getting started

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Explore projects and apply filters from the search panel.

Because the site is entirely static, you can also deploy it directly through GitHub Pages or any static hosting service without additional build steps.

## Project structure

```
├── index.html    # Main application shell and layout
├── style.css     # Global styles and responsive design rules
└── script.js     # Sample project data and interactive filtering logic
```

## Deployment on GitHub Pages

1. Push the repository to GitHub.
2. Enable GitHub Pages in the repository settings (choose the `main` branch and `/ (root)` directory).
3. The site will be available at `https://<username>.github.io/<repository-name>/`.
